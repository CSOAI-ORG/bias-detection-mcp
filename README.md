## Configuration

Add to your `claude_desktop_config.json` (Claude Desktop) or your MCP client config:

```json
{
  "mcpServers": {
    "bias-detection-mcp": {
      "command": "uvx",
      "args": ["bias-detection-mcp"]
    }
  }
}
```

Or: `pip install bias-detection-mcp` then run the `bias-detection-mcp` command (stdio transport).
